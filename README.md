# Golf Tempo Trainer

iOS app for training golf swing tempo using the **3:1 backswing-to-downswing ratio** — the ratio consistent across all tour professionals (Novosel Tour Tempo research).

Voice cues generated by ElevenLabs. Audio plays with screen off / app backgrounded.

---

## Tempo Science

| | Backswing | Downswing | Ratio | BPM equiv |
|---|---|---|---|---|
| **Gear 1 (Fast)** | 0.63s | 0.21s | 3:1 | 88 |
| **Gear 2 (Medium)** | 1.00s | 0.33s | 3:1 | 72 |
| **Gear 3 (Slow)** | 1.13s | 0.38s | 3:1 | 60 |
| **Wedge** | 20% faster than full swing, same ratio | | | |

Tour average: Gear 2. Most amateurs swing at 2:1 (rushing the downswing) — Gear 3 is the recommended starting point.

## Setup

### Requirements
- Xcode 15+
- iOS 16+ device or simulator
- ElevenLabs free account (10,000 chars/month free)

### Build with xcodegen (recommended)

```bash
brew install xcodegen
cd golf-tempo-trainer
xcodegen generate
open GolfTempoTrainer.xcodeproj
```

### Manual Xcode setup

1. Open Xcode → File → New → Project → iOS App
2. Name: `GolfTempoTrainer`, Bundle ID: `com.p55t.GolfTempoTrainer`
3. Delete the generated files; drag all `.swift` files from this repo into the project
4. Add `GolfTempoTrainer/Resources/Audio/` folder to the project (check "Copy items if needed")
5. In Info.plist add `UIBackgroundModes` → `audio`

### ElevenLabs API Key

The key is set in `ContentView.swift` (`elevenLabsKey`). On first launch, tap **Prepare Audio Cues** — this calls ElevenLabs once and caches the files locally. Pre-generated `back.mp3` and `hit.mp3` are bundled in `Resources/Audio/` so the API call is not needed if they load from the bundle.

---

## How It Works

1. Select **Full Swing** or **Wedge**
2. Select tempo **Gear** (start with Gear 3 if you're a beginner)
3. Tap **Start Training**
4. On each cycle: hear **"Back"** → swing back → hear **"Hit"** → swing through
5. Lock your screen — audio continues

The app uses `AVAudioSession.Category.playback` which keeps audio alive when the screen locks or the app moves to background.
